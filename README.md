Entry for the [make.fun bounty](https://make.fun/bounty/u-eager-stork-81-9647-funniest-sign-on-a-haunted-ab1d019a): one funny line for the door of a haunted server room, max 120 characters.

## The sign

> DO NOT REBOOT: the ghost in Rack 7 is mid-update and he has root. Knock twice. He IS the firewall now.

## How it works

`main.py` writes that single line to `/output/entry.txt` (program/v1), self-checking the 1–120 character gate and the single-line rule. `OUTPUT_DIR` overrides the output directory for local runs.
